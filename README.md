# Final Fantasy Tactics Advance Recomp — русский перевод Maksami

Русская адаптация [ffta-recomp](https://github.com/james2doyle/ffta-recomp) на основе **v2.1** с переводом **Maksami audit-1.26**.

**Текущий этап — подготовка исходников и проверка совместимости.** Подготовка русской ROM проверена. Нативные сборки Windows и Android и прохождение в рекомпиляции ещё требуют проверки.

## Что добавлено

- Русский текст игры и глоссарий audit-1.26 в папке translation.
- Настройки генерации и запуска под точную русскую ROM.
- Подключение проверенного BPS-патча в настольном загрузчике.
- Настройки импорта русской ROM и русские подписи подготовки на Android.
- Инструмент подготовки ROM с проверкой контрольных сумм.

Исходный проект поддерживает Windows, Linux, Steam Deck и Android. Эти платформы остаются целями русской адаптации. Перевод системного меню рекомпиляции и проверка широкого экрана входят в дальнейшую работу.

## Подготовка

Понадобятся собственный ROM **Final Fantasy Tactics Advance (USA)** и патч **audit-1.26** из раздела [Releases](https://github.com/Maksamiweb/ffta-recomp-ru/releases).

Из корня репозитория выполните одной строкой:

    python tools/prepare_russian_rom.py --source "/path/to/Final Fantasy Tactics Advance (USA).gba" --patch "/path/to/FFTA-USA-RU-demo-1.26.bps"

Скрипт создаёт локальный game.gba для сборочных инструментов. При повторном запуске он проверяет уже подготовленный файл. Оригинал ROM и патч сохраняются.

## Контрольные суммы

| Файл | SHA-1 |
|---|---|
| Оригинал USA, 16 777 216 байт | 4ac05441f4de70a4ec3dd932116346c61b8783d9 |
| Перевод audit-1.26, 18 036 544 байта | ff29faf0da37332e77524236f6966633ec51139d |

SHA-256 патча — 3c94b0a09f99dfc9845e3c045e0cf0c78ad24b2dd48b2e7c94434645d8646c8c.

Все значения закреплены в translation/release.json. Настольная сборка проверяет исходный USA ROM и результат применения перевода. Android настроен на импорт заранее подготовленного game.gba.

## Сборка из исходников

Нативная сборка требует Linux x86-64, CMake, Ninja и компилятор C++17. Windows-версия собирается через MinGW, Android требует JDK, SDK и NDK. Полный порядок описан в [руководстве сборки](docs/manual-build.md).

    git submodule update --init --recursive
    python3 build.py

После изменения ROM необходимо заново сгенерировать нативный код. Готовые английские EXE/APK v2.1 привязаны к оригинальной ROM.

## Сохранения

Внутриигровое сохранение FFTA представляет собой flash-файл на 65 536 байт. В настольной сборке путь — saves/ffta_us.sav. Перед переносом сделайте копию.

Быстрые состояния RetroArch, VBA Next и mGBA содержат память конкретного ядра и версии ROM. Для переноса в рекомпиляцию используйте внутриигровое сохранение. Совместимость прохождения из русской версии в нативной сборке ещё предстоит проверить.
